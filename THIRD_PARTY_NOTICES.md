## Noto Sans Thai

The site (home page and every built guide) uses Noto Sans Thai as the primary
UI font. The file shipped here is `template/fonts/noto-sans-thai.woff2`.

- Copyright 2022 The Noto Project Authors (https://github.com/notofonts/thai)
- Upstream: Noto Sans Thai version 2.002, variable font
  `NotoSansThai[wdth,wght].ttf` from the
  [google/fonts `ofl/notosansthai`](https://github.com/google/fonts/tree/main/ofl/notosansthai)
  package (sources: https://github.com/notofonts/thai).
- This copy is a modified build for the web: the width axis is fixed at the
  default 100, and the weight axis is kept for 400–700 so Regular (400),
  SemiBold (600) and Bold (700) stay real weights. The glyph set is the
  upstream Thai and Latin coverage. It is not loaded from Google Fonts.
- The upstream copyright statement names no Reserved Font Name, so the family
  name stays "Noto Sans Thai". Noto is a trademark of Google Inc.
