โหมดเชื่อมต่อ และการจับคู่

จอยมี 3 ช่องทางเชื่อมต่อ: มีสาย (USB-C), Bluetooth 5.2, และ StrikeSpeed 2.4 GHz (ดองเกิล)

สวิตช์โหมดด้านหลัง (P) ในแผนภาพคู่มือพิมพ์ว่า NS/BT / ⚡ และแผนภาพแสดงตำแหน่งปุ่มสวิตช์ 2 ด้าน

  • ด้าน NS/BT (แผนภาพไฮไลต์ด้านที่มีไอคอนแบบ Switch): ใช้ตอนเชื่อมต่อบลูทูธ และตอนต่อสายเข้า Switch / Switch 2
  • ด้าน ⚡ (แผนภาพเลื่อนปุ่มไปทางขวา): ใช้ตอนเชื่อมต่อ StrikeSpeed / ดองเกิล 2.4 GHz

แถวต่อสายเข้าพีซีในคู่มือไม่ได้ระบุว่าต้องตั้งสวิตช์ไปด้านใด

คู่มือไม่ได้เขียนขั้นตอนเปิด-ปิดเครื่องทั่วไป นอกจากขั้นตอนกดค้างปุ่ม Home 3 วินาทีในโหมดบลูทูธ

แบบมีสาย — WIRED CONNECTION (PC, SWITCH, SWITCH 2)

แหล่งที่มา: คู่มือ QSG ส่วน HOW TO CONNECT

  • พีซี: ต่อพอร์ต USB-C ของจอยกับสาย แล้วต่อหัว USB-A เข้าพีซี แผนภาพแถวนี้ไม่มีคำแนะนำเรื่องสวิตช์โหมด
  • Switch / Switch 2: ตั้งสวิตช์โหมดไปด้าน NS/BT แล้วต่อสาย USB-C ไปยังหัว USB-A เข้าแท่นของ Switch / Switch 2

บลูทูธ — BT CONNECTION (PC และ SWITCH / SWITCH 2 และสมาร์ตโฟน)

แหล่งที่มา: คู่มือ QSG ส่วน HOW TO CONNECT

  1. ตั้งสวิตช์โหมดไปด้าน NS/BT
  2. กดค้างปุ่ม Home (ปุ่มโลโก้ Fantech) 3 วินาที
  3. บนอุปกรณ์ ให้เลือกชื่อ ZENITH PRO
  4. แผนภาพแสดงอุปกรณ์ปลายทางเป็นพีซี, Android, iOS, Switch / Switch 2

คู่มือไม่ได้ระบุขั้นตอนเมนู Change Grip/Order ของ Switch หรือชื่อที่ระบบบลูทูธอาจแสดงต่างออกไปจาก "ZENITH PRO"

StrikeSpeed 2.4 GHz — STRIKESPEED CONNECTION

แหล่งที่มา: คู่มือ QSG ส่วน HOW TO CONNECT แผนภาพระบุปลายทางเป็น PC และ SWITCH / SWITCH 2 และสมาร์ตโฟน

  1. ตั้งสวิตช์โหมดไปด้าน ⚡
  2. เสียบดองเกิล USB เข้าพีซี, Android, iOS หรือ Switch / Switch 2 โดยตรง หรือเสียบดองเกิลเข้าช่องบนแท่นชาร์จ แล้วต่อพอร์ต USB-C ของแท่นชาร์จด้วยสาย USB-C ไปยังหัว USB-A เข้าพีซี

เชิงอรรถในคู่มือ: การต่อเข้า Switch, Android หรือ iOS ต้องรองรับ OTG สำหรับ iOS แนะนำพอร์ต Type-C เช่น iPhone 15 ขึ้นไป

คู่มือมีปุ่มจับคู่บนดองเกิล (V) และไฟสถานะบนดองเกิล (U) ในส่วน Product Tour แต่ไม่มีขั้นตอนว่าเมื่อไรต้องกดปุ่มจับคู่บนดองเกิล

การสลับโหมดอินพุต X-Input / D-Input / Switch Input

แหล่งที่มา: คู่มือ QSG ส่วน INPUT MODE SWITCH

  • ใช้ได้เฉพาะโหมด 2.4 GHz และแบบมีสาย (ข้อความในคู่มือ: "Mode Switching is only available in 2.4GHz and Wired Mode")
  • กดค้าง SHARE + OPTION พร้อมกัน จอยจะสั่นเพื่อยืนยัน จากนั้นวนโหมดซ้ำได้ด้วยปุ่มผสมเดิม
  • คู่มือระบุโหมดเริ่มต้นเป็น X-Input แล้วสลับครั้งแรกเป็น D-Input ครั้งถัดไปเป็น Switch Input

สีไฟที่ระบุในหัวข้อนี้ไม่ตรงกับตาราง LED INDICATOR ในแผ่นเดียวกัน ดังนี้

โหมดสีไฟตามหัวข้อ INPUT MODE SWITCHสีไฟตามตาราง LED INDICATOR
X-Input (ค่าเริ่มต้น)LED 2 สีแดงคงที่เชื่อมต่อสำเร็จ: LED 1 เขียวคงที่, LED 3 แดงคงที่
D-InputLED 1 น้ำเงินคงที่ + LED 2 แดงคงที่LED 1 เขียวคงที่, LED 2 น้ำเงินคงที่, LED 3 แดงคงที่
Switch InputLED 1 น้ำเงินคงที่LED 1 เขียวคงที่, LED 2 น้ำเงินคงที่

ทั้งสองชุดมาจากคู่มือ QSG แผ่นเดียวกัน เอกสารไม่ได้ระบุว่าชุดใดเป็นชุดที่แก้ไขแล้ว

จากรีวิว ไม่ใช่คู่มือ: รีวิว HL Planet ระบุว่าโหมดอินพุต X-input, D-input และ Switch ใช้ได้ทั้งแบบมีสาย, บลูทูธ และดองเกิล 2.4 GHz และให้ปุ่มสลับเป็น View + Menu (ชื่อเดียวกับ Share + Option) ข้อที่ต่างจากคู่มือคือคู่มือจำกัดการสลับโหมดไว้แค่ 2.4 GHz กับแบบมีสาย

ฟังก์ชันปุ่ม

แหล่งที่มาของแรงสั่น เทอร์โบ และมาโครบนแพดเดิล คือคู่มือ QSG

แรงสั่น (Rumble)

  1. กดค้างปุ่ม M พร้อมดัน L3 ขึ้นหรือลง
  2. จอยจะสั่น และความแรงของการสั่นแสดงระดับปัจจุบัน
  3. มี 4 ระดับ: 100% / 70% / 35% / 0%

เทอร์โบ และออโต้เทอร์โบ

  1. เปิดเทอร์โบ: กดค้าง M แล้วกดปุ่มที่ต้องการกำหนด
  2. เปิดยิงอัตโนมัติ (Auto-Fire): กดค้าง M แล้วกดปุ่มที่กำหนดเทอร์โบไว้แล้วอีกครั้ง
  3. ยกเลิกเทอร์โบ: กดค้าง M แล้วกดปุ่มที่กำหนดไว้อีกครั้ง
  4. ปรับความเร็ว: กดค้าง M แล้วดัน R3 ขึ้นหรือลง เพื่อวนระดับความเร็ว

ใช้ได้กับปุ่มกดหน้า (Action Buttons), LT, RT, RB, LB ความเร็วมี 3 ระดับ: 100%, 50% (ค่าเริ่มต้น), 25%

มาโคร (Macro) บนแพดเดิลหลัง M1 / M2

กำหนดมาโคร

  1. กดค้าง M + แพดเดิลหลัง (ซ้ายหรือขวา) นาน 2 วินาที
  2. เมื่อไฟ LED กะพริบ ให้กดปุ่มที่ต้องการบันทึก
  3. กดแพดเดิลหลัง (ซ้ายหรือขวา) เพื่อยืนยันและบันทึก

ลบมาโคร

  1. ทำขั้นตอนเดิม แล้วกดแพดเดิลหลังโดยไม่กดปุ่มใด
  2. มาโครถูกลบ

คู่มือระบุว่าบันทึกได้สูงสุด 16 ปุ่ม และมาโครจะหยุดเองหลังไม่มีการใช้งาน 5 นาที

จากรีวิว ไม่ใช่คู่มือ: รีวิว HL Planet ระบุว่าแอป KeyLinker รองรับมาโครสูงสุด 24 สเต็ปในกรอบ 5 นาที ซึ่งต่างจากตัวเลข 16 ปุ่มในคู่มือ

  • ปรับค่าได้ขณะจอยยังต่อกับพีซีหรือ Switch อยู่
  • ในแอปมี: รีแมปปุ่ม (ไม่รองรับอินพุตคีย์บอร์ด/เมาส์), ตั้งค่าแท่งอนาล็อกและทริกเกอร์, เทอร์โบ, มาโคร, คาลิเบรต, ปรับเวลาสลีป, หน้าจอทดสอบอินพุต, คืนค่าเริ่มต้น, อัปเดตเฟิร์มแวร์
  • แรงสั่น, เทอร์โบ, รีแมปปุ่มหลัง และคาลิเบรต ทำด้วยปุ่มบนตัวจอยได้โดยไม่ต้องเปิดแอป

ลิงก์ร้านแอปสาธารณะของ KeyLinker (ไม่ได้โฮสต์บนเว็บ Fantech): App Store, Google Play

ไฟ RGB

หน้าสินค้าระบุว่ามีไฟ RGB คู่มือ QSG ไม่มีหัวข้อปรับหรือปิดไฟ RGB

จากรีวิว ไม่ใช่คู่มือ: รีวิวระบุปุ่มลัดที่ไม่มีในคู่มือ (ทั้ง HL Planet และ HungryGeeks ระบุชัดว่าไม่ได้อยู่ในคู่มือ)

  • กดค้าง M + กดคลิกสติ๊กขวา (R3/RS) นาน 5 วินาที เพื่อปิดไฟ RGB ทั้งชุด
  • กด M แล้วดันสติ๊กซ้ายซ้ายหรือขวา เพื่อปรับความสว่าง (ระบุใน HL Planet)

แบตเตอรี่และการชาร์จ

จากหน้าสินค้าและคู่มือ:

  • แบตเตอรี่ 800 mAh Li-ion (หน้าสินค้า)
  • ใช้งานได้สูงสุดประมาณ 8 ชั่วโมง (QSG และหน้าสินค้า)
  • ชาร์จประมาณ 2 ชั่วโมง (ตารางเปรียบเทียบในหน้าสินค้า)
  • ชาร์จผ่านพอร์ต USB-C บนตัวจอย (N) หรือผ่านแท่นชาร์จที่แถมในกล่อง (พอร์ต T บนแท่น)
  • แท่นชาร์จมีช่องเก็บดองเกิล (S)

คู่มือ QSG ไม่มีหัวข้อขั้นตอนการชาร์จ และไม่มีคำอธิบายไฟระหว่างชาร์จ

จากรีวิว ไม่ใช่คู่มือ:

  • แท่นชาร์จใช้แม่เหล็กจัดตำแหน่ง และมีแถบไฟ RGB ที่ซิงก์กับจอยขณะวางชาร์จ (HL Planet)
  • มีฟังก์ชัน Smart Sleep / Wake-up: วางจอยลงแท่นแล้วจอยหลับและเริ่มชาร์จ ยกขึ้นแล้วเชื่อมต่อใหม่อัตโนมัติ (HL Planet)
  • การปลุกเครื่อง (wake-up) ใช้ได้กับ Switch รุ่นเดิม แต่ใช้ไม่ได้กับ Switch 2 (HL Planet)
  • เวลาใช้งานจริงราว 8 ชั่วโมง ขึ้นกับแรงสั่นและความสว่าง RGB (HL Planet)

ซอฟต์แวร์และเฟิร์มแวร์

  • คู่มือ QSG: ให้เข้า www.fantechworld.com เพื่อดาวน์โหลดซอฟต์แวร์หากมี
  • หน้าสินค้า: โปรแกรมปุ่มผ่านแอปมือถือ Keylinker
  • หน้าดาวน์โหลดทางการ (Download - All และ Download - Console): มีลิงก์ Quick Start Guide ของ ZENITH PRO WGP18 เท่านั้น ไม่มีไฟล์เฟิร์มแวร์หรือซอฟต์แวร์พีซี
  • คู่มือทางการไม่มีขั้นตอนอัปเดตเฟิร์มแวร์ รีวิว HL Planet ระบุว่าอัปเดตเฟิร์มแวร์ทำได้ในแอป KeyLinker แต่ไม่ได้ลงรายละเอียดขั้นตอน

การคาลิเบรต และการรีเซ็ตโรงงาน

แหล่งที่มา: คู่มือ QSG

คาลิเบรต

  1. ปิดจอยให้เรียบร้อย
  2. กดค้าง L3 + HOME + RB จนไฟสถานะเริ่มกะพริบ
  3. กดปุ่ม A เพื่อเริ่มคาลิเบรต
  4. หมุนแท่งอนาล็อกรอบเต็มวงอย่างช้า ๆ
  5. กดทริกเกอร์ลงช้า ๆ ขณะยังหมุนแท่งเป็นวง
  6. เมื่อคาลิเบรตเสร็จ กด A อีกครั้งเพื่อยืนยัน ไฟสถานะจะเป็นสีเขียวคงที่ถ้าสำเร็จ

คู่มือไม่ได้ระบุว่าต้องคาลิเบรตสติ๊กซ้าย ขวา หรือทริกเกอร์ข้างใดบ้างแยกกัน และไม่ได้ระบุวิธีเมื่อคาลิเบรตไม่สำเร็จ

รีเซ็ตโรงงาน (Factory Reset)

  1. กดค้าง L3 + R3 + M พร้อมกัน
  2. ไฟของจอยจะกะพริบแล้วดับ เพื่อยืนยันว่ารีเซ็ตสำเร็จ

ข้อความต้นฉบับในคู่มือ: "The controller light will flashes and shut off to confirm a successful reset."

การแก้ปัญหา

คู่มือ QSG ไม่มีหัวข้อ Troubleshooting สิ่งที่ใกล้เคียงที่สุดคือการคาลิเบรตและการรีเซ็ตโรงงานในหัวข้อก่อนหน้า หน้าดาวน์โหลดของรุ่นนี้ก็ไม่มีเอกสาร FAQ

ข้อมูลที่ไม่มีในแหล่งทางการ หรือยังกำกวม

  • รองรับ Steam Deck หรือไม่
  • ขั้นตอนเปิด-ปิดเครื่องทั่วไป และเวลาเข้าสู่โหมดสลีปจากตัวจอยโดยไม่ใช้แอป
  • วิธีใช้ Trigger Lock ทีละขั้น (มีแค่ชื่อชิ้นส่วนใน QSG และคำอธิบายสั้น ๆ ในหน้าสินค้า)
  • วิธีใช้ไจโร / motion control ทีละขั้น
  • ขั้นตอนกดปุ่มจับคู่บนดองเกิล และการจับคู่ดองเกิลใหม่เมื่อเชื่อมไม่ติด
  • ขั้นตอนเมนูจับคู่บน Nintendo Switch (Change Grip/Order) และบน iOS / Android / macOS / tvOS / Tesla / Game Pass / Steam โดยเฉพาะ
  • ตำแหน่งสวิตช์โหมดตอนต่อสายเข้าพีซี
  • แถวไฟ LED สำหรับโหมด StrikeSpeed และสถานะระหว่างชาร์จ
  • สีไฟในหัวข้อสลับโหมดอินพุตขัดกับตาราง LED ในคู่มือแผ่นเดียวกัน
  • ขั้นตอนปรับหรือปิดไฟ RGB ในคู่มือ (มีเฉพาะในรีวิว)
  • ซอฟต์แวร์พีซี ไฟล์เฟิร์มแวร์ และขั้นตอนอัปเดตเฟิร์มแวร์ทางการ
  • ระยะสัญญาณไร้สายทางการ (รีวิว HungryGeeks ทดลองได้ราว 10 เมตร แต่หน้าสินค้า WGP18 ไม่ระบุตัวเลขนี้)
  • คู่มือเป็น Quick Start Guide แผ่นเดียว ไม่ใช่คู่มือฉบับเต็ม

หมายเหตุเรื่องรีวิวที่ไม่ได้ใช้เป็นแหล่งหลัก: รีวิว Retro Handhelds (4 มิ.ย. 2026) ใส่ซอฟต์แวร์ในตารางสเปกว่า Flydigi Space Station ซึ่งขัดกับหน้าสินค้าของ Fantech ที่ระบุ Keylinker จึงไม่นำค่านี้มาใช้

เก็บเช็กลิสต์ไว้ใน GitHub Gist แบบ secret ของตัวเอง ไม่ตั้งค่าก็ใช้ได้ตามปกติ ข้อมูลอยู่ในเครื่องนี้

  1. สร้าง secret Gist ที่ gist.github.com ตั้งชื่อไฟล์ checklist.json ใส่เนื้อหา {} แล้วคัดลอก ID ท้าย URL
  2. สร้าง fine-grained token ที่ GitHub › Settings › Developer settings ให้สิทธิ์เฉพาะ Gists (อ่าน/เขียน) แทน classic PAT ที่ติ๊ก gist
  3. ตั้งวันหมดอายุของ token ไว้ด้วย เช่น 90 วัน

token เก็บไว้ในเบราว์เซอร์นี้ (ใช้ร่วมกันทุกหน้าใน palathip.github.io) และส่งไปที่ api.github.com เท่านั้น
