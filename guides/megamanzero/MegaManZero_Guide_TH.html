เนื้อเรื่องและอ้างอิง

ฐานฐาน Resistance (ของหลังภารกิจ 1 และ 2)เนื้อเรื่องสรุปเนื้อเรื่อง Mega Man Zero 1สปอยล์สปอยล์: ภาค 2 ถึง 4 ไปต่อยังไงลิงก์แหล่งข้อมูล

ไม่พบผลลัพธ์ ลองค้นด้วยคำอื่น

คู่มือ Mega Man Zero ภาคแรกบน GBA เรียงตามลำดับภารกิจ แต่ละภารกิจมีเช็กลิสต์ Cyber-elf ชิป และอาวุธ ตามด้วยทริกผ่านด่านและวิธีสู้บอส ติ๊กช่องเมื่อเก็บได้แล้ว เบราว์เซอร์จะจำไว้ให้ เนื้อเรื่องภาคต่ออยู่ในหัวข้อสปอยล์ท้ายหน้า ซึ่งปิดไว้ก่อน

ความคืบหน้า

  • Elf Cyber-elf: 78
  • Weapon อาวุธ: 3
  • Chip ชิปธาตุ: 3
  • Item ไอเทมสำคัญ: 1

อ่านก่อนเล่น

ภารกิจที่ล้มเหลวจะเล่นซ้ำไม่ได้ ถ้ากด Escape Unit, เลือก Give Up ตอน Game Over หรือกด Abort Mission ภารกิจนั้นจะหายไปถาวร พร้อม Cyber-elf และชิปที่อยู่ในด่าน ควรเซฟก่อนลงด่านทุกครั้ง พลาดเมื่อไหร่ให้โหลดเซฟใหม่

  • Cyber-elf ใช้ได้ครั้งเดียวแล้วตาย และทุกตัวที่ใช้จะถูกหักคะแนนตอนจบภารกิจ ตัวที่หายากโดนหักมากกว่า
  • เข้าห้องบอสตอนแรงก์ A หรือ S บอสจะใช้ท่าพิเศษ EX Skill เพิ่มมา ถ้าเล่นเอาเนื้อเรื่องอย่างเดียวไม่ต้องสนใจแรงก์ แรงก์ต่ำบอสยิ่งง่าย
  • ชิปธาตุชนะกันเป็นวง: ไฟชนะน้ำแข็ง น้ำแข็งชนะสายฟ้า สายฟ้าชนะไฟ ธาตุออกเฉพาะตอนตีแบบชาร์จเต็ม
  • Cyber-elf ในกล่องเกือบทุกตัวกลับมาเก็บทีหลังได้ ส่วนตัวที่ได้จากการฆ่าศัตรูต้องเก็บระหว่างทำภารกิจนั้นเท่านั้น
  • Cyber-elf บางตัวต้องป้อน E-Crystal ให้ครบก่อนถึงจะใช้ได้ ถ้าเลี้ยงทุกตัวรวมกันต้องใช้ราว 23,150 EC

ลำดับภารกิจที่แนะนำ

  1. ภารกิจ 1: ช่วย Ciel ได้ Z-Saber
  2. ภารกิจ 2: Disposal Center ได้ Thunder Chip และ Escape Unit
  3. Retrieve Data (บอสแพ้สายฟ้า) ได้ Triple Rod จาก Cerveau และได้ Shield Boomerang หลังจบอีกหนึ่งภารกิจ
  4. Destroy Train (บอสแพ้สายฟ้า)
  5. Occupy Factory ได้ Flame Chip
  6. Find Shuttle (บอสแพ้ไฟ)
  7. Find Hidden Base (บอสแพ้ไฟ) ได้ Ice Chip
  8. หุ่นยักษ์บุกฐาน โผล่มาเองหลังเคลียร์ครบ 4 ภารกิจ
  9. Rescue Colbor (บอสแพ้น้ำแข็ง)
  10. Protect Factory
  11. Duel in Desert (บอสแพ้สายฟ้า)
  12. Stop the Hacking (บอสแพ้ไฟ)
  13. ช่วงท้าย: ฐานโดนบุก, Shrine, Tower แล้วจบที่ Core

ลำดับนี้ปรับจาก StrategyWiki ซึ่งให้ทำ Retrieve Data เป็นอันสุดท้าย เพราะพอเคลียร์ด่านนี้ รังแมงมุมในแล็บที่ใช้ฟาร์ม E-Crystal จะหายไป ที่นี่ย้ายขึ้นมาเป็นอันที่ 3 เพื่อให้ได้ Triple Rod กับ Shield Boomerang เร็วขึ้นสำหรับคนเล่นเนื้อเรื่อง ต้องเก็บ Clocpah ก่อนกดเริ่ม Retrieve Data และเก็บ Nuppie ก่อนเคลียร์ด่านนี้

01 – ช่วย Ciel (Golem)

5 ชิ้น

Elf×4 Weapon×1

เช็กลิสต์ของสะสม

  • Stoccue — ทำลายรังแมงมุม (Spider Nest) 5 รัง ในด่านมีแค่ 4 รัง ทำลายรังแรกแล้วถอยออกจากจอนิดหนึ่ง รังจะเกิดใหม่
  • Stocchu — ทำลาย Pantheon Guardian สีฟ้า 5 ตัว อยู่ช่วงหลังรังที่ 4
  • Nuppie (+HP) — กล่องอยู่ในห้องสูงขึ้นไปในแล็บ มี E-Crystal 16 อันอยู่ด้วย กลับมาเก็บทีหลังได้ แต่ต้องก่อนเคลียร์ Retrieve Data

ทิปบอส/การสู้

  • บอส Golem: ยิง Buster ใส่หัว ระวังโดน Ciel สักพักจะมีแสงลึกลับมามอบ Z-Saber ให้ เปิดเมนูใส่ดาบแล้วฟันหัวทีเดียวจบ
  • ห้องนี้ฟาร์ม E-Crystal และอัปอาวุธได้ดี แต่ฟาร์มได้จนกว่าจะเคลียร์ Retrieve Data

  • ทริกด่าน: Contrainer เปลี่ยนทิศลมทุกครั้งที่โดนตี 2 ที ถ้าไม่ตีมัน ลมจะดันให้วิ่งเร็วขึ้น แต่ก็อาจพาไปชนศัตรู ด่านนี้จำกัดเวลา Cyber-elf สายนาฬิกาช่วยได้
  • บอส Aztec Falcon: มีเวลา 1:19 นาทีก่อน Reploid จะโดนบี้ เกาะผนังฝั่งตรงข้ามกับมันไว้ พอมันแดชเข้ามาให้ฟันแล้ววิ่งไปผนังอีกฝั่ง ท่าของมันมียิงธนูไฟฟ้า 3 ดอก, แดชข้ามฉาก, ยิงธนูทีละดอก และสร้างกำแพงไฟฟ้า เลือดมีหลอดเดียว ไม่ยาก

03 – Retrieve Data (Maha Ganeshariff)

6 ชิ้น

Elf×4 Weapon×2

เช็กลิสต์ของสะสม

  • Bomga — ทำลาย Clopper
  • Sticker — ทำลายรถถังสีเขียว (Green Tank)
  • Itecle — ได้จากบอส
  • Somack — กล่องในพื้นที่ใหม่บนสุดของปล่อง เปิดให้เข้าหลังจบภารกิจ
  • Triple Rod — คุยกับ Cerveau ที่ฐานหลังจบภารกิจ
  • Shield Boomerang — คุยกับ Cerveau อีกครั้งหลังจบภารกิจถัดไป

ทิปบอส/การสู้

  • ทริกด่าน: มีใบพัดไฟฟ้าหมุนที่ทำลายไม่ได้ ต้องจับจังหวะผ่าน (ถ้ามีชิปน้ำแข็ง ตีชาร์จจะแช่แข็งมันได้) ระเบิดลอยก็เยอะกว่ารอบแรก
  • ช่วงหนี: ล้มบอสแล้วเพดานจะถล่มไล่หลัง ประตูฉุกเฉินปิดขวางเป็นระยะ ฟันประตูให้แตกแล้ววิ่งกลับไปที่ปล่องต้นด่านให้ทัน
  • บอส Maha Ganeshariff (แพ้สายฟ้า): ตอนมันกลิ้งเป็นลูกบอลให้กระโดดหลบ ถ้ามันเอางวงห้อยเพดานแล้วแกว่ง ให้ฟันโซ่เพื่อหยุดท่านี้ ตอนมันตบมือรัวๆ ยิง Buster ให้ลอยข้ามมือไปโดนหัวได้

  • ด่านนี้ต้องสู้บอสเก่าซ้ำก่อนเจอ Copy X ชิปที่ควรใส่ดูได้จากตารางจุดอ่อน
  • Copy X ร่างแรก (ไม่แพ้ธาตุไหน): ตัวกะพริบแปลว่ากำลังเปลี่ยนธาตุ กระสุนจะเปลี่ยนตาม กระสุนน้ำแข็งแตกเป็น 5 ชิ้น ลูกไฟฟ้าตามตัวได้นิดหน่อย ไฟพุ่งเป็นเส้นโค้ง ถ้ามันชาร์จ นัดถัดไปจะแรงขึ้น และมีท่าสไลด์กับ Nova Strike ที่พุ่งตามตัว ตอนแรงก์ A หรือ S มันจะเติมเลือดเต็ม 1 หลอดแล้วอมตะไปพักหนึ่ง
  • Copy X ร่างสอง (แพ้น้ำแข็ง): ตอนยิงเลเซอร์มั่ว (Tentei Laser) ให้แดชจากปลายแท่นข้างหนึ่งไปอีกข้าง เลเซอร์จะพลาดหมด วงแหวนผูกมัดไม่ทำดาเมจ ขยับหลบก็พอ ระวังลำแสงที่ไล่เผาพื้น ถ้าได้ยินเสียงหัวเราะหลอนๆ มันกำลังจะทุบแท่นหนามลงมา (ท่า EX)
  • Hafmargo หรือ Hafmarda ใช้กับบอสตัวนี้คุ้มที่สุด

สรุปเนื้อเรื่อง Mega Man Zero 1

เรื่องเกิดราว 100 ปีหลังภาค Mega Man X ตอนนั้นทั้ง X และ Zero หายตัวไปนานแล้ว Neo Arcadia นครอุดมคติของมนุษย์ปกครองโดย "X" แต่กลับตีตรา Reploid ว่าเป็น Maverick แล้วกำจัดทิ้งโดยไม่ไต่สวน Ciel นักวิทยาศาสตร์สาวจึงหนีออกมาตั้งกลุ่ม Resistance ต่อต้าน

ฉากแรก Ciel กับลูกน้องถูกกองทัพ Pantheon ไล่ล่าเข้าไปในแล็บร้าง แล้วเจอ Zero ที่หลับมาร้อยปี Passy Cyber-elf ของ Ciel ยอมสละชีวิตปลุก Zero ขึ้นมา Zero ตื่นมาความจำเสื่อม แต่ตัดสินใจช่วย Ciel และเข้าร่วม Resistance

Zero รับภารกิจต่างๆ เพื่อซื้อเวลาให้ Ciel สร้างแหล่งพลังงานใหม่ จนวันหนึ่ง Neo Arcadia บุกฐาน Ciel สารภาพว่าเธอเป็นคนช่วยสร้าง Neo Arcadia เอง พอเกิดวิกฤตพลังงานและ X ตัวจริงหายไป เธอสร้าง Copy X ขึ้นมาเป็นผู้นำแทนตั้งแต่อายุ 6 ขวบ Copy X อยากได้โลกที่สงบแบบ X ตัวจริง แต่ไม่มีวิจารณญาณแบบต้นฉบับ เลยตัดสินว่า Reploid เป็นภัยต่อมนุษย์และกำจัดพวกเขาเพื่อประหยัดพลังงาน

Zero บุกเข้า Neo Arcadia และสู้ผ่านสี่ผู้พิทักษ์ (Four Guardians) คือ Harpuia, Phantom, Fefnir และ Leviathan Phantom ระเบิดตัวเองหวังเอา Zero ไปด้วยแต่ไม่สำเร็จ อีกสามคนหนีไปได้ สุดท้าย Zero ล้ม Copy X ได้ Copy X ระเบิดฐานหวังให้ตายด้วยกัน Zero หนีออกมาทันแล้วหมดแรงล้มลงกลางทะเลทราย

ตอนจบ X ตัวจริงซึ่งตอนนี้เป็น Cyber-elf ปรากฏตัว บอกว่าคอยนำทาง Zero มาตลอด เขาเหนื่อยกับการต่อสู้และไม่มีร่างกายเหลือแล้ว จึงฝากโลกไว้กับ Zero พอ X หายไป กองทัพ Pantheon ก็ล้อม Zero ไว้ เขาประกาศว่าจะสู้กับ Neo Arcadia ต่อ แล้วพุ่งเข้าใส่ฝูง Pantheon เป็นฉากสุดท้าย

ซิงก์เช็กลิสต์ข้ามเครื่อง

เก็บเช็กลิสต์ไว้ใน GitHub Gist แบบ secret ของพี่เอง ไม่ตั้งค่าก็ใช้ได้ตามปกติ ข้อมูลอยู่ในเครื่องนี้

  1. สร้าง secret Gist ที่ gist.github.com ตั้งชื่อไฟล์ checklist.json ใส่เนื้อหา {} แล้วคัดลอก ID ท้าย URL
  2. สร้าง fine-grained token ที่ GitHub › Settings › Developer settings ให้สิทธิ์เฉพาะ Gists (อ่าน/เขียน) แทน classic PAT ที่ติ๊ก gist
  3. ตั้งวันหมดอายุของ token ไว้ด้วย เช่น 90 วัน

token เก็บไว้ในเบราว์เซอร์นี้ (ใช้ร่วมกันทุกหน้าใน palathip.github.io) และส่งไปที่ api.github.com เท่านั้น
