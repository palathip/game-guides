ซิงก์เช็กลิสต์ข้ามเครื่อง

เก็บเช็กลิสต์ไว้ใน GitHub Gist แบบ secret ของตัวเอง ไม่ตั้งค่าก็ใช้ได้ตามปกติ ข้อมูลอยู่ในเครื่องนี้

  1. สร้าง secret Gist ที่ gist.github.com ตั้งชื่อไฟล์ checklist.json ใส่เนื้อหา {} แล้วคัดลอก ID ท้าย URL
  2. สร้าง fine-grained token ที่ GitHub › Settings › Developer settings ให้สิทธิ์เฉพาะ Gists (อ่าน/เขียน) แทน classic PAT ที่ติ๊ก gist
  3. ตั้งวันหมดอายุของ token ไว้ด้วย เช่น 90 วัน

token เก็บไว้ในเบราว์เซอร์นี้ (ใช้ร่วมกันทุกหน้าใน palathip.github.io) และส่งไปที่ api.github.com เท่านั้น
